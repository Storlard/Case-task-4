# Case-task-4
## Интерактвный калькулятор

Веб-калькулятор, реализованный с использованием HTML, CSS и JavaScript. Позволяет выполнять базовые математические операци над двумя числами.

---
## Функциональность
Приложение поддерживает следующие операции:
- сумма
- разность
- произведение
- деление

---
## Интерфейс
- 2 поля для чисел
- 4 кнопки для выбора операции
- поле для отображения результатов

---
## Обработка ошибок
Програма обрабатывает следующие случаи:
- ввод пустых значений
- ввод нечисловых данных
- деление на ноль

В случае ошибки выводятся сообщения (в зависимости от ошибки):
- Ошибка: введите корректные числа
- Ошибка: деление на ноль
